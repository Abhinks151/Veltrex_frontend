# Veltrex

A simple-to-use MES (Manufacturing Execution System) style CNC operations management platform.

---

## Getting Started

Before starting, ensure you have ran `pnpm install` in the frontend directory.

### Frontend (`/veltrex-frontend`)
React + Vite + TypeScript

| Command | Description |
| :--- | :--- |
| `pnpm dev` | Start development server |
| `pnpm build` | Build for production |
| `pnpm lint` | Run ESLint check |
| `pnpm lint:fix` | Run ESLint and fix issues |
| `pnpm format` | Format code with Prettier |
| `pnpm preview` | Preview production build |

### Tech Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Shadcn UI
- Redux Toolkit
- React Router
- Axios

- **Frontend**: `http://localhost:5173`
